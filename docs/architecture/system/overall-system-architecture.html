Overall System ArchitectureImplemented

The full request and deployment topology: the Vue SPA served through Nginx, the Go API server and worker as separate binaries sharing the same internal packages, RabbitMQ as the only channel between them, and SQL Server reached from outside the Docker Compose network.

Implementation Notes

  • Nginx reverse-proxies both /api/ and /swagger/ to the backend container on :8080 — the frontend never calls the backend from outside the Compose network.
  • There are exactly two real RabbitMQ producers: the report-export handler (on demand) and a server-owned ticker that scans for overdue stock adjustments every 30 seconds.
  • The worker also consumes a development-only heartbeat queue (wms.system.health) alongside its two real business queues.
  • backend and worker are separate deployable Go binaries that both import the same internal/ packages (config, database, rabbitmq) — this is shared compiled code, not a network call between them.
  • SQL Server is not a Docker Compose service in this UAT configuration; all three Go binaries reach it via DB_HOST=host.docker.internal.
