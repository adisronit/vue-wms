System Architecture

How the pieces of the WMS monorepo fit together: the request path from browser to database, the frontend's component structure, the backend's layering, and how it's all deployed with Docker Compose.

Overall System ArchitectureImplemented

Browser → Nginx → Go API → SQL Server / RabbitMQ → Worker, end to end.

Frontend Component ArchitectureImplemented

Vue Router, MainLayout, 20 views, the hand-rolled fetch service layer — no Pinia.

Backend Layered ArchitectureImplemented

3 entrypoints, 20 business modules, shared platform packages, the RBAC middleware chain.

Deployment ArchitecturePartial — UAT variant

Docker Compose services, volumes, and the externally-hosted SQL Server deviation.
