Program Workflows

Every business process traced end-to-end: trigger endpoint, validation, business rules, transaction boundaries, error/rollback behavior, and completion — each claim backed by a file:line citation into the actual Go source.

AuthenticationImplemented

Login, bcrypt, JWT issuance with permissions embedded at login time.

ReceivingImplemented

Confirm receipt lines, mutate inventory via AddStockTx, idempotent by key.

PutawayImplemented

Move stock from staging to a STORAGE-zone location via MoveStockTx.

Inventory Management (Core)Implemented

The shared AddStock/RemoveStock/MoveStock/Reserve library every workflow calls into.

PickingImplemented

Reserve at creation, consume at confirm, release on short-pick or cancel.

ShippingImplemented

Requires a completed picking task; never touches inventory itself.

Stock AdjustmentImplemented

A controlled correction document — inventory only mutates at Approve.

Stock CountImplemented

Freezes expected qty, applies variance on Confirm with a stale-balance conflict check.

Reservation & CancellationImplemented

Lives inside Inventory Core (reserved_quantity), not a dedicated module.
