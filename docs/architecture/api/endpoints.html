API Endpoint ReferenceImplemented

Every REST endpoint actually wired up in cmd/server/main.go, grouped by module in registration order. All paths are mounted under /api/v1. "Auth" shows the real middleware chain — most routes are RequireJWT → RequirePermission(code) → Handler; a few are JWT-only or fully public. Live, testable docs: Swagger UI (when the backend is running).

Swagger / OpenAPI

  • Mounted conditionally: cmd/server/main.go:196-199 — only when SWAGGER_ENABLED is true. Reachable at http://localhost:8080/swagger/index.html.
  • Top-level doc block: cmd/server/main.go:1-11 — @title Smart WMS API, @BasePath /api/v1, @securityDefinitions.apikey BearerAuth.
  • Every protected handler carries @Security BearerAuth matching its real middleware wiring; public handlers (auth.Login, health.Get) omit it — annotations are synchronized with actual code, not aspirational.
