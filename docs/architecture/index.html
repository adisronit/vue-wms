5 · Known Gaps & Deviations

Surfaced explicitly rather than glossed over — found while tracing the actual code, not assumed from the spec.

  • Gap No purchase-order entity — Receiving's expected_qty is user-entered at creation, never validated against an external PO/ASN record.
  • Gap No location capacity/volume constraint — Putaway only checks the destination zone's type is STORAGE, not any numeric capacity.
  • Gap No explicit row-locking or optimistic-version column on inventory — concurrency safety relies entirely on single-statement guarded UPDATEs plus DB CHECK constraints.
  • Deviation The committed docker-compose.yml is a UAT configuration with no containerized SQL Server — all three Go binaries reach SQL Server on the host via host.docker.internal.
  • Dead code fontend/src/views/inventory/NewStockAdjustmentView.vue exists on disk but is never imported or routed anywhere.
  • Stale doc PROJECT_STATUS.md claims QC/Putaway/Shipping roles have zero permissions — the current internal/rbac/catalog.go grants them real permission sets; the doc comment predates a later-phase fix.
